# Checkpoint 4 — real ingestion and local demo pipelines

Checkpoint 4 replaces the in-memory API with PostgreSQL persistence, authenticated versioned report ingestion and a local Pipeline Lab. The platform retains fictional seeded history while clearly identifying new `DEMO_PIPELINE` executions.

Implemented formats are real Mochawesome from Cypress, `playwright-json-v1` from Playwright, and `mobile-e2e-json-v1` from the explicit `MOBILE_HARNESS_DEMO`. An infrastructure run has no functional approval result.

Local completion evidence belongs below `artifacts/checkpoint-4/<timestamp>` and contains ten screenshots plus a SHA-256 manifest. Artifacts are not versioned.

Publication, remote creation and push remain outside this checkpoint.
