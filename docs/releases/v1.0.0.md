# QualityOps Hub v1.0.0

Status: **published final release**

QualityOps Hub v1.0.0 packages the completed public portfolio experience: a hosted TestOps dashboard, authenticated external-CI ingestion, normalized multi-framework results, historical quality metrics, and public proof from real browser workflows.

## Highlights

- React and Fastify hosted together on Render with same-origin API access.
- PostgreSQL persistence on Neon.
- Real Cypress/Mochawesome and Playwright/`playwright-json-v1` ingestion from GitHub Actions.
- Product-scoped hashed tokens, strict schemas, idempotent replay, and HTTP 409 conflict handling.
- Official-data isolation: only authenticated `EXTERNAL_CI` results drive aggregate quality metrics.
- Execution history, pipeline traceability, Regression Delta, Coverage, Integrations, Execution Details, and Pipeline Lab.
- Responsive portfolio UI, defensive HTTP headers, health/readiness checks, and public-release scans.

## Architecture

```text
GitHub Actions
-> Cypress / Playwright
-> retained report artifact
-> authenticated Fastify ingestion API on Render
-> versioned adapter
-> normalized execution
-> Neon PostgreSQL
-> React dashboard on Render
```

Browser automation stays in GitHub Actions because the free hosted service is designed for the application and API, not browser-heavy workers. The hosted Pipeline Lab remains a non-persisting preview and is not official evidence.

## Known limitations

- All portfolio products and data are fictional and synthetic.
- PocketWallet uses a deterministic mobile harness rather than a real Android device.
- Render Free can cold-start.
- There is no user authentication, multi-tenancy, distributed job queue, or distributed rate limiting.
- Object storage and persistent Video Evidence are not enabled.
- The hosted Pipeline Lab previews the flow but does not run browsers or create official executions.
