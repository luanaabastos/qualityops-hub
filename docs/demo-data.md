# Demo Data

The repository ships synthetic data for three fictional products to demonstrate trends without implying real usage.

## Products

- ShopSphere — Cypress / Mochawesome
- ServiceDesk — Playwright / JSON + JUnit
- PocketWallet — Appium/WebdriverIO / mobile-e2e-json-v1

## Behaviors

- ShopSphere contains a few recent regressions and recoveries.
- ServiceDesk has one stale execution window.
- PocketWallet includes an infrastructure error followed by recovery.

This creates realistic dashboard and history patterns without pretending that the dataset is production data.
